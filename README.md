# DVC remote storage (read-only)

This branch is a content-addressed [DVC](https://dvc.org) remote for the `solution` branch of
[datsabk/dvc-tutorial](https://github.com/datsabk/dvc-tutorial). DVC reads it over HTTPS from
`https://raw.githubusercontent.com/datsabk/dvc-tutorial/storage`. You never need to check it out.
